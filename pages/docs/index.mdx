# Get Started with DF Documentation

[Dora Factory](https://dorafactory.org/) is the digital infrastructure of the Global Hacker Movement.

It creates protocols, toolings, and public good infrastructures that help open source communities and frontier tech builders to thrive.

## Quickstart

import sharingPages from '../../.generated/seo.json'

export const QUICKSTART_ROUTES = [
  '/docs/vota-amaci',
  '/docs/vota',
  '/docs/vota-dev',
  '/docs/vota-devops',
  '/docs/qrng'
]

<Cards num={2}>
  {QUICKSTART_ROUTES.map(route => {
    const page = sharingPages[route]
    return (
      <Cards.Card key={route} image arrow title={page.title} href={route}>
        <img
          width={page.image.width}
          height={page.image.height}
          alt={page.image.alt}
          src={page.image.url}
        />
      </Cards.Card>
    )
  })}
</Cards>
